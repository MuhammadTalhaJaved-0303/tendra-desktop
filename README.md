# Primal Code Desktop

Desktop builds of [Primal AI](https://ai-video-generation-ruddy.vercel.app)'s Primal Code, the agentic coding studio.

Grab the latest build from [Releases](https://github.com/MuhammadTalhaJaved-0303/tendra-desktop/releases/latest):

- **Windows**: `Tendra-Setup-Windows-x64.exe` (the filename is kept stable so existing links keep working; the app installs as Primal Code)
- **macOS**: coming soon

These are beta builds and are not code-signed yet, so your OS will warn on first launch:

- **Windows**: SmartScreen may show "Windows protected your PC"; choose **More info > Run anyway**.

The app is a thin native shell over the hosted studio, so it always runs the latest version of Primal AI. Source lives in the main (private) repository.
