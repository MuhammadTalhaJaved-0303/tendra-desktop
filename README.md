# Tendra Desktop

Desktop builds of [Tendra](https://ai-video-generation-ruddy.vercel.app) Code, the agentic coding studio.

Grab the latest build from [Releases](https://github.com/MuhammadTalhaJaved-0303/tendra-desktop/releases/latest):

- **Windows**: `Tendra-Setup-Windows-x64.exe`
- **macOS** (Apple Silicon + Intel): `Tendra-macOS-universal.dmg`


- **macOS**: right-click the app and choose **Open** (needed once).
- **Windows**: SmartScreen may show "Windows protected your PC"; choose **More info > Run anyway**.

The app is a thin native shell over the hosted studio, so it always runs the latest version of Tendra. Source lives in the main (private) Tendra repository.
